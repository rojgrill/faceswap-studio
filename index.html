How it works

Quality comes from the pipeline, not the raw model.

Every face goes through the same seven-stage path. Each stage exists to fix what the stage before it got slightly wrong.

STAGE 01

Detect & embed

SCRFD finds every face, ArcFace extracts a 512-d identity embedding so the right person is swapped.

buffalo_l · det_10g + w600k_r50
STAGE 02

Align

Similarity transform (Umeyama, pure NumPy) maps the face into a canonical 512px space — up to 1024px for large faces.

ALIGN_SIZE=512 · ALIGN_MAX=1024
STAGE 03

Swap

inswapper_128 generates the new face at 128px, then it is upscaled back into the aligned frame.

inswapper_128.onnx
STAGE 04

Parse & mask

BiSeNet face parsing builds a mask that protects glasses, hair and hands — only skin gets replaced.

face_parsing_resnet18
STAGE 05

Restore

Optional GPEN/GFPGAN recovery with adaptive strength: small faces get more help, large faces stay natural.

gpen512 · gfpgan · auto_strength()
STAGE 06

Color & light

LAB color transfer inside the mask, then spatial illumination matching for rim light and shadows.

color_match 0.6 · illum_match 0.5
STAGE 07

Seamless blend

Feathered edge plus Poisson seamless clone, then the face is pasted back at the original resolution.

seamless=True · feather=12
VIDEO MODE

Streaming + tracking

Frame-by-frame streaming with IoU face tracking, temporal EMA smoothing and scene-cut detection, audio preserved.

detect_every=3 · ema=0.65

Modes

One mode picker: Fast to Max quality.

Touch any setting and the mode switches to Custom automatically. Auto picks for you after a first-run benchmark.

Fast

  • Detection size 320
  • Re-detect every 5 frames
  • No restoration, illum 0.0
  • Linear blend, no hires pass

Balanced

  • Detection size 640
  • Re-detect every 3 frames
  • Illumination match 0.45
  • Seamless clone + hires pass

Max quality

  • Detection size 768 (the ceiling)
  • Re-detect every 2 frames
  • gpen512 restoration at 0.55
  • Illum 0.6, feather 16, hires

Auto

  • Benchmarks your hardware once
  • Picks provider: CUDA → DML → CPU
  • Chooses a preset that fits your speed
  • Re-runs whenever hardware changes

Command line

Every feature is scriptable.

The GUI and the CLI share one core, so batch jobs and tests run exactly the same pipeline.

PowerShell — faceswap
# hardware + provider probe
python -m cli hw

# fetch and verify all models
python -m cli download --all
python -m cli verify

# swap a face in an image
python -m cli swap -s src.jpg -t tgt.jpg -o out.png --preset balanced

# process a video (audio preserved)
python -m cli video -s src.jpg -t clip.mp4 -o out.mp4 --preset fast

# safeguards are on by default
python -m cli swap ... --no-watermark --no-metadata

# full-line self test (0 = OK)
python main.py --selftest
result: OK

What you get

  • Same pipeline — CLI results match the GUI exactly, no “demo mode”.
  • Headless tests — quality, safeguards, features, hires, blend and batch scripts all exit non-zero on failure.
  • Self-test — runs detect + embed + swap on bundled samples; essential for catching packaging mistakes.
  • Benchmarks — cli bench measures your machine and feeds Auto mode.
  • Environment control — FACESWAP_PROVIDER, FACESWAP_DATA_DIR, FACESWAP_LOG_LEVEL, FACESWAP_CPU_THREADS, HF_TOKEN.
  • Portable build — pyinstaller faceapp.spec produces a one-folder exe with ffmpeg included.
Hardware

The best provider that actually works.

Every backend is probed with a real model before it is used — if DirectML misbehaves on your GPU, the app silently falls back to CPU instead of crashing.

Priority 1

CUDA

NVIDIA GPUs — the fastest path, orders of magnitude above CPU on video.

onnxruntime-directml / CUDA EP
Priority 2

DirectML

Any GPU on Windows. Probe-tested first — rejected if SCRFD reshapes fail.

cache/provider_probe.json
Fallback

CPU

Always available. Expect roughly 0.5–1 fps on 720p video; use the Fast preset.

FACESWAP_CPU_THREADS=auto

FAQ

Common questions.

Does anything leave my computer?

No. Detection, swapping, restoration and encoding all run locally. Internet is only used once, to download the models — and video encoding uses a locally bundled ffmpeg.

Why is video slow on my machine?

On CPU, expect roughly 0.5–1 frame per second at 720p. Switch to the Fast preset (detection 320, no restoration) and use face tracking so detection runs every 5 frames instead of every frame. On a CUDA GPU, video is dramatically faster.

My GPU is detected but the app reports CPU. Is that a bug?

It is deliberate. Each provider is tested with a real model first — on some older GPUs DirectML fails a SCRFD reshape check, so the app falls back silently. Details are in logs/app.log; run with FACESWAP_LOG_LEVEL=DEBUG for more.

Where are models stored, and can I share them between installs?

Next to the exe by default (dist\FaceSwapStudio\models). Set FACESWAP_DATA_DIR in a .env file to point several copies at one shared model cache. Every file is verified against models/.manifest.json.

Can I publish the results?

Only with the consent of every person shown, and keep the watermark and metadata tag on — they are enabled by default precisely so viewers can tell AI-modified content apart.

Which Python version is supported?

Python 3.12.8 is the tested release (3.11 works). Python 3.13 is not supported because of insightface and numpy < 2 constraints.
